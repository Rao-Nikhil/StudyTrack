# Project Statement — StudyTrack

## Problem Statement
Students often keep study activity and assessment results in separate notes or files, making it difficult to see how study time relates to academic performance. StudyTrack provides one command-line system for maintaining student information, recording study sessions, storing assessment results, and viewing basic performance analytics.

## Scope
The project covers student record management, study-session recording, assessment recording, validation, JSON persistence, analytics, leaderboard generation, recommendations, and text report generation. It is intentionally designed as a terminal application so it can be executed without a GUI.

## Target Users
- Students who want to track their study activity and assessment performance.
- Faculty or mentors who need a small local record-management utility for demonstration purposes.

## High-Level Features
1. Student CRUD operations.
2. Study-session recording.
3. Assessment score recording and percentage calculation.
4. Student performance analytics.
5. Leaderboard generation.
6. Personalized rule-based study recommendations.
7. Text report generation.
8. JSON-based persistent storage.
9. Input validation and error handling.
10. Unit tests for core functionality.
